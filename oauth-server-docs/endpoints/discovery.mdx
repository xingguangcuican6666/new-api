<Info>
`GET /.well-known/openid-configuration`
</Info>

返回 OpenID Connect 发现文档（OpenID Connect Discovery 1.0），列出授权服务器的端点与能力。无需认证，可缓存（`Cache-Control: public, max-age=3600`）。

标准 OIDC 客户端库通常只需这一个地址即可自动完成端点配置。

## 请求

无参数、无需认证。

```bash
curl https://your-newapi.example.com/.well-known/openid-configuration
```

## 响应

```json
{
  "issuer": "https://your-newapi.example.com",
  "authorization_endpoint": "https://your-newapi.example.com/oauth2/authorize",
  "token_endpoint": "https://your-newapi.example.com/oauth2/token",
  "userinfo_endpoint": "https://your-newapi.example.com/oauth2/userinfo",
  "jwks_uri": "https://your-newapi.example.com/oauth2/jwks",
  "revocation_endpoint": "https://your-newapi.example.com/oauth2/revoke",
  "scopes_supported": ["openid", "profile", "email", "groups", "api_keys"],
  "response_types_supported": ["code"],
  "response_modes_supported": ["query"],
  "grant_types_supported": ["authorization_code", "refresh_token"],
  "subject_types_supported": ["public"],
  "id_token_signing_alg_values_supported": ["RS256"],
  "token_endpoint_auth_methods_supported": [
    "client_secret_basic",
    "client_secret_post",
    "none"
  ],
  "code_challenge_methods_supported": ["S256"],
  "claims_supported": [
    "iss", "sub", "aud", "exp", "iat", "auth_time", "nonce",
    "preferred_username", "name", "email", "email_verified", "groups", "role"
  ]
}
```

## 字段说明

<ResponseField name="issuer" type="string">
  Issuer 标识。所有端点 URL 都由它拼接得到（去除结尾斜杠）。
</ResponseField>
<ResponseField name="authorization_endpoint / token_endpoint / userinfo_endpoint / jwks_uri / revocation_endpoint" type="string">
  各端点的绝对地址。
</ResponseField>
<ResponseField name="scopes_supported" type="string[]">
  支持的 scope：`openid`、`profile`、`email`、`groups`、`api_keys`。
</ResponseField>
<ResponseField name="response_types_supported" type="string[]">
  仅 `code`。
</ResponseField>
<ResponseField name="response_modes_supported" type="string[]">
  仅 `query`（授权响应以查询参数回传）。
</ResponseField>
<ResponseField name="grant_types_supported" type="string[]">
  `authorization_code`、`refresh_token`。
</ResponseField>
<ResponseField name="subject_types_supported" type="string[]">
  `public`。
</ResponseField>
<ResponseField name="id_token_signing_alg_values_supported" type="string[]">
  `RS256`。
</ResponseField>
<ResponseField name="token_endpoint_auth_methods_supported" type="string[]">
  `client_secret_basic`、`client_secret_post`（机密客户端），`none`（公开客户端）。
</ResponseField>
<ResponseField name="code_challenge_methods_supported" type="string[]">
  `S256`。
</ResponseField>
<ResponseField name="claims_supported" type="string[]">
  可能返回的全部 claims。
</ResponseField>

## 错误

授权服务器未启用时返回 `404`：

```json
{ "error": "not_found", "error_description": "the OAuth authorization server is not enabled" }
```
